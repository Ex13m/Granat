# Задание для Claude Code

## Цель

Залить проект «Гранатовая охота» в репозиторий https://github.com/Ex13m/Granat, поднять его на GitHub Pages и доработать до состояния «одна ссылка — один игрок».

## Контекст

Игорь, Прага. Проект — полевой квест для отца с тремя детьми девяти лет: приезжаешь на парковку в Подседице, идёшь 2,7 км по полевой дороге на запад и собираешь чешские пиропы в пашне и в гравии ручья.

Сейчас в папке лежит `index.html` — самодостаточное одностраничное приложение без зависимостей. Внутри: GPS-наводка (стрелка + метры), мини-карта на SVG без тайлов, десять квестов с автозакрытием по геозонам, счётчики находок на трёх игроков, камера для фотожурнала, голосовые подсказки через `speechSynthesis` на русском, прогресс в `localStorage`.

Репозиторий создан и пуст. Netlify и Supabase у Игоря подключены, аккаунт GitHub — Ex13m.

Ключевое ограничение среды: в поле нет мобильной связи. Всё, что требует сети в момент игры, использовать нельзя — ни картографических тайлов, ни CDN, ни шрифтов с внешних хостов.

## Ограничения

- Ноль внешних зависимостей в рантайме. Никаких npm-пакетов в бандле, никаких CDN, никаких внешних шрифтов.
- Приложение остаётся одним файлом `index.html` в корне репозитория — так работают и Pages, и Netlify Drop без конфигов.
- Геолокация требует HTTPS, это учесть при проверке.
- Не трогать координаты точек и радиусы срабатывания в `TARGETS` — они выверены по месту.
- Ветка `main`, коммиты осмысленные, без «update».

## Критерии качества

- Репозиторий содержит `index.html`, `README.md`, `.gitignore`; Pages отдаёт рабочую страницу по `https://ex13m.github.io/Granat/`.
- На старте новый игрок вводит имя, дальше ведётся один счётчик находок вместо трёх; имя сохраняется в `localStorage`.
- Старый прогресс на три игрока не ломает приложение при открытии новой версии — миграция или чистый сброс с понятным сообщением.
- Проверено на Android Chrome: разрешение геолокации, срабатывание квеста по входу в радиус, голос по-русски, съёмка фото и её сохранение после перезагрузки.
- Приложение открывается и полностью работает в авиарежиме после первого захода.

## Формат вывода

Сначала диффы по файлам с коротким пояснением, что меняется и зачем. После подтверждения — коммит, пуш, включение Pages, и в ответе одна строка с готовой ссылкой.

Отдельно перечислить, что осталось незакрытым, если что-то не удалось проверить.

Применение: фон шапки приложения, кадр меняется по мере прохождения — 1 до выхода на грунтовку, 3 в зонах поиска, 2 после первой находки, 4 на финальном квесте. Поверх картинки затемняющий градиент, чтобы текст читался на солнце.

Движение обязательно: медленный наезд, `transform: scale(1)` → `scale(1.12)` за 14 секунд, `ease-out`, затем плавный возврат. Статичная картинка не годится. Уважать `prefers-reduced-motion`.

Если суммарный вес всех четырёх выходит больше 400 КБ — резать качество, а не выкидывать кадры. Картинки должны лежать в репозитории, а не тянуться с внешнего хоста: в поле сети нет.

## Следующий шаг, отдельной задачей

Общее табло на троих детей через Supabase: одна таблица с именем, счётчиком и временем последней находки, запись по анонимному ключу, опрос раз в 15 секунд при наличии сети и очередь отложенной отправки при её отсутствии. Делать только после того, как основная версия отработает в поле.
