# ПИРОП РАШ · гранатовая охота

Офлайн-квест по гранатовым полям между Подседице и Држемчице (Чешское Средогорье).
Один HTML-файл, без зависимостей, без сети. GPS, голосовые подсказки, фотожурнал, прогресс в localStorage.

## Запуск

Открыть `index.html` в браузере. Для геолокации нужен HTTPS или localhost.

## Деплой

- Netlify Drop: перетащить `index.html` на app.netlify.com/drop
- GitHub Pages: положить `index.html` в корень ветки main, включить Pages (Settings → Pages → Deploy from a branch → main → /root)
- Репозиторий: https://github.com/Ex13m/Granat

## Что внутри

- `TARGETS` — точки с радиусами срабатывания и текстом голосовой подсказки
- `QUESTS` — 10 заданий, закрываются по входу в радиус, по счётчику находок или по фото
- `RANKS` — звания по количеству найденного
- мини-карта на SVG, рисуется от GPS в локальных координатах, тайлы не нужны
- стрелка-наводка: bearing и расстояние до активной цели
- `speechSynthesis` ru-RU, срабатывает один раз на каждую зону за сессию

## Правила по месту

Металлоискатель на полях не использовать: земля частная, Газмбурк — памятник археологии.
В посевы не заходить, ходить по краям и полевым дорогам. Копать лопатой нельзя, сбор с поверхности.

## Комикс-режим (версия 2)

Приложение открывается интро-комиксом из шести страниц: что за камни, кто в отряде,
какие у героев приёмы, как читать стрелку, правила поля, старт. Комикс можно открыть
в любой момент кнопкой «комикс» внизу.

Стиль: граффити-аниме-дримкор — неоновые пятна на фоне, зерно, панели комикса с
жёсткой обводкой, речевые бабблы с пояснениями к каждому экрану.

### Три героя

| Герой | Роль | Приём | Что делает приём |
|-------|------|-------|------------------|
| КАПИ | сканер, ведёт детектор | СКАН | называет текущую цель и расстояние до неё |
| ТЕНЬ | следопыт, читает землю | ЧУЙКА | выдаёт случайный совет поиска из шести |
| ЛИНЗА | копатель, бьёт по комкам | РАЗЛОМ | три минуты каждый камень идёт за два |

Приём перезаряжается 15 минут. Аватары нарисованы SVG прямо в файле — внешних картинок нет.
Имена редактируются прямо на карточке и сохраняются в `localStorage`.

### Задания и значки

13 заданий: путевые (закрываются по входу в радиус зоны), командные (по общему счётчику),
персональные (по счётчику конкретного героя) и фото. У каждого задания есть строка
«зачем» — пояснение детским языком, почему это делается именно так.

Семь значков отряда: первый камень, все трое в деле, 3 фото, десятка, три приёма,
обе красные зоны, квест пройден.

### Совместимость

Прогресс старой версии (три безымянных счётчика) мигрирует автоматически: находки,
закрытые задания и фото переносятся, имена подставляются, если были заданы.

## Арт (версия 3)

Восемь кадров сгенерированы в Higgsfield (`gpt_image_2_5`) в едином стиле
«граффити-аниме-дримкор» и лежат в `img/` как webp. Суммарный вес — 96 КБ,
внешних запросов в рантайме нет, всё работает в самолётном режиме.

| Файл | Что на кадре | Где используется |
|------|--------------|------------------|
| `a1.webp` | Капи — кепка с нашивкой, детектор | аватар героя 1 |
| `a2.webp` | Тень — чёрная кепка, руки скрещены | аватар героя 2 |
| `a3.webp` | Линза — очки, лопата на плече | аватар героя 3 |
| `b4.webp` | отряд уходит по полевой дороге на закате | шапка до выхода на грунтовку |
| `b5.webp` | гранаты в детской ладони, макро | шапка 22 секунды после каждой находки |
| `b6.webp` | трое детей шеренгой вдоль борозды | шапка в зонах поиска |
| `b7.webp` | Газмбурк на закате | шапка на финальном квесте |

Шапка живёт: медленный наезд `scale(1) → scale(1.13)` за 16 секунд с возвратом,
кросс-фейд между кадрами и глитч-вспышка в момент смены. При
`prefers-reduced-motion: reduce` движение отключается.
